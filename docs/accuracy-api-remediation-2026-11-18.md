## 准确率修复

| 项目 | 改动与边界 |
| --- | --- |
| A1 历史年份 | 问题中明确的 `YYYY年` 参与沿革代际选择，以该年末为取点；多个年份取可读代际并集。显式 `as_of` 优先。普通文档不套用“当年入库”的限制，仍取当前保存版本。精确标题、显式文档 ID 和所有 ACL 检查保留。年份追问替换旧年份并保留主题。年份内发生多次变更时，需要明确 `as_of` 才能表达具体日期。 |
| A2 核验误杀 | 句末引用可以位于粗体/下划线等强调标记内外，断句仍保留引用归属；无引用句、错号、错误数字与单位仍拒答。图谱有效期继续用于检索筛选，不再在生成提示中把抽取的起止日期、状态、置信度展示成可引用证据；提示明确要求答案复述的日期和有效期必须来自编号原文。没有扩大数字白名单。 |
| A3 对比证据 | 各对比子查询轮转取得不重复的最佳证据，再补剩余名额，避免低分一侧被全局排序截掉。预算至少覆盖各子查询各一条。对比项共用的主题补入各子查询。 |
| A4 个人记忆 | 个人情况/偏好问题可使用当前用户未过期的相关记忆，编号接在文档证据之后，继续经过逐句引用和语义核验。引用标为“个人记忆”，在私人会话中保存原文快照，重开会话仍可查看；文档 ID 和切块 ID 为 NULL。公共政策问题不提供记忆证据，不会把记忆写入事实库。已同步 schema 注释。 |

## API 修复

| 项目 | 当前行为 |
| --- | --- |
| B1 replay 无 body | 按空对象处理，缺省执行检索回放；提供的 top_k 校验范围。 |
| B2 非法价格 | provider/model 必须为非空字符串，价格为非负有限数值，币种为三个大写字母，日期必须真实有效；拒绝未知字段，价格字段名为 input_per_1m/output_per_1m。非法请求在 SQL 前返回 400。 |
| B3 ACL 元素类型 | 非数组、非字符串元素、空白主体均在入队前返回 400；直接调用摄入核心也校验。 |
| B4 空 ACL | 显式空数组返回 400，不会转为全员可见。省略 ACL 仍保持现有约定：新文档全员可见，更新文档保留原授权。私有文档须显式授权当前用户。 |
| B5 幽灵组 | 仅接受本租户现存活跃用户/组及 tenant:public，并要求上传者仍可读，防止创建上传者无法管理的文档；没有扩大删除权限。 |
| B6 空白文本 | 非字符串或纯空白文本在入队前返回 400。 |
| B7 空白记忆 | 非字符串或纯空白内容返回 400，保存前去除首尾空白。 |
| B8 越界参数 | 共用 integerParam 对低于/高于范围的整数统一返回 400；列表、图谱 hops/limit、费用 days 和回放 top_k 使用相同规则。 |
| B9 会话状态码 | 不存在、跨用户或跨租户会话在提问入口统一返回 404，与 GET 一致。 |
| B10 标题上限 | 显式标题在入队前校验，摄入核心也校验解析后标题，最长 500 个 UTF-16 代码单元。 |
| B11 SSRF 同步拒绝 | URL 首跳在入队前调用原有 DNS/IP 校验，失败返回 400；后台仍逐跳校验并固定连接 IP，保留 DNS 重绑定防护。 |
| B12 上传类型 | 非 multipart 上传返回 415。 |
